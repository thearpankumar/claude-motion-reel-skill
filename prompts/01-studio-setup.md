# Chapter 1: Set up the studio

Turns an empty folder into a motion studio: toolchain check, Playwright with Chromium, and the house rules file.

## Prompt

```text
Set this folder up as a motion design studio. Check what's already installed and only install what's missing:
- Node 22+, ffmpeg, and Python with numpy, librosa and soundfile
- npm init -y, then install Playwright with Chromium (npm i -D playwright && npx playwright install chromium)
Then create CLAUDE.md in the project root with the rules I paste next. Confirm each step when it's done.
```

## Make it yours
Run it once per machine. Paste the rules from `02-house-rules.md` when it asks, or copy this kit's `CLAUDE.md` into your project root.
